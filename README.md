# Watermark App

A desktop watermarking tool built with **Tauri 2 + React + TypeScript** for local-first image processing. It helps you apply branded text/logo overlays, preview changes instantly, and export single or batch outputs without uploading files to external services.

## Why this project exists

Most quick watermark tools are either web-only, limited, or not ideal for repeat workflows. This app focuses on a practical desktop workflow: import, tune placement/opacity, compare before/after, save presets, and export consistently.

## Key Features

- **Interactive watermark canvas** with drag, resize, rotate, and zoom controls.
- **Text watermark controls** for content, size, color, opacity, and placement presets.
- **Optional logo watermark layer** with independent transform and opacity controls.
- **Before/after preview mode** to verify readability and placement.
- **Preset system** to save and reuse watermark configurations.
- **Single and batch export** workflows.
- **PNG and JPG output** (JPG quality control supported).
- **Local desktop export via Tauri command** (no cloud dependency required).

## How it works (high-level architecture)

1. The user imports a base image (and optional logo image).
2. Watermark state (text/logo styles + positions) is maintained in React state.
3. The preview canvas renders overlays with deterministic geometry utilities.
4. On export, the composition is rendered to an off-screen canvas.
5. The generated bytes are sent to a Tauri command that writes the final image to disk.

## Usage

1. Open the app and import a base image.
2. Edit text watermark content and appearance.
3. (Optional) Import a logo watermark and adjust transform settings.
4. Toggle before/after preview and fine-tune placement.
5. Export a single image, or queue multiple images for batch export.
6. Save your watermark configuration as a preset for reuse.

## Example workflow output

- Input: `product-shot.png` + text watermark + logo overlay.
- Output: `product-shot.watermarked.png` (or `.jpg`) saved to local disk.

## Engineering Decisions

- **Local-first export path:** avoids sending images to external APIs.
- **Separated logic modules (`src/lib`)** for geometry, rendering, and persistence concerns.
- **Stateful but explicit UI flow:** keeps interaction complexity manageable without introducing heavy state libraries.
- **Preset persistence:** improves repeatability for real-world watermarking tasks.

## Challenges addressed

- Maintaining intuitive drag/resize behavior while preserving watermark bounds.
- Keeping rendered output consistent with preview behavior.
- Handling both single-image and batch workflows through one UI shell.
